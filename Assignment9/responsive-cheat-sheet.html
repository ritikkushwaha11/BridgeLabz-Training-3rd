Responsive CSS Cheat Sheet

Four useful concepts for modern layouts.

Filters

Change the visual appearance of images or elements.

filter: grayscale(100%);

Media Queries

Apply styles when the viewport meets a condition.

@media (max-width: 700px) { ... }

Responsive Design

Make layouts adapt to different screen sizes.

width: 100%; max-width: 1200px;

Typography

Scale text smoothly with flexible font sizes.

font-size: clamp(1rem, 2vw, 1.5rem);
