Responsive Design Principles

Three foundations of a responsive website.

Fluid Layouts

Use flexible proportions instead of fixed page widths so content can expand or shrink.

.container {
  width: 90%;
  max-width: 1200px;
  margin: auto;
}

Flexible Media

Images and videos should fit inside their containers without overflowing.

img, video {
  max-width: 100%;
  height: auto;
}

Breakpoints

Use media queries to adjust the layout at useful screen widths.

@media (max-width: 600px) {
  .layout {
    grid-template-columns: 1fr;
  }
}
