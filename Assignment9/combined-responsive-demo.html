Responsive Design

Responsive design uses flexible layouts, flexible media, and breakpoints so a page remains useful on phones, tablets, and desktop screens.

Flexbox is useful for one-dimensional alignment, while Grid organizes content into rows and columns.

Cheat Sheet Preview

  • Grid: display: grid;
  • Flexbox: display: flex;
  • Breakpoint: @media (max-width: 700px)
