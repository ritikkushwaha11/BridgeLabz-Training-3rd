# JavaScript Function Assignment — Solutions

This folder contains separate beginner-friendly JavaScript files for all 9 questions in `Submission of JS Function.pdf`.

## Files
1. `Q1_Callback_Function.js` — callbacks and greeting flow
2. `Q2_Apply_Operation.js` — callback operations (double and square)
3. `Q3_Arrow_Function_This.js` — arrow function `this` vs normal function
4. `Q4_Car_Prototype.js` — constructor and shared prototype method
5. `Q5_Person_Student_Prototype.js` — prototype inheritance
6. `Q6_Person_Faculty_Professor.js` — multi-level prototype chain
7. `Q7_Closure_Multiplier.js` — closures
8. `Q8_Custom_Array_myMap.js` — custom array `myMap()` method
9. `Q9_ES6_Class_Inheritance.js` — `Person` and `Student` with ES6 classes

## How to run
1. Install Node.js if it is not already installed.
2. Open a terminal in this folder.
3. Run one file at a time, for example:

   ```bash
   node Q1_Callback_Function.js
   ```

Each file includes comments and sample output/usage. Use only core JavaScript (ES6+); no frameworks are required.
