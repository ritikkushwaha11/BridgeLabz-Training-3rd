# JavaScript ES Features Assignment — Solutions

This folder contains one runnable JavaScript file for each of the 10 questions in
`Lec7-10 JS ES Feature Assignment.pdf`.

## Run the solutions
1. Install Node.js if it is not already installed.
2. Open this folder in VS Code.
3. Run a file in the terminal, for example:
   `node Q1_Dynamic_Data_Parser.js`
4. Repeat for Q2 through Q10.

## Files
- Q1: Dynamic Data Parser
- Q2: Employee Bonus Calculator
- Q3: Transaction Validator
- Q4: Debugging Mystery
- Q5: Hoisting Lab
- Q6: Pyramid Pattern Generator
- Q7: Smart Calculator
- Q8: Strict Mode Showdown
- Q9: JSON Audit
- Q10: Nested Hoisting and Closures

Each file uses console output and includes comments explaining relevant logic,
hoisting, scope, validation, or debugging observations. Q4/Q5/Q8/Q10 include
debugger guidance as comments; set breakpoints in VS Code to observe live state.
