# JavaScript Classes Assignment 4 — Solutions

This folder contains solutions for all 9 questions from the supplied assignment.

## How to run
- **Q1, Q3, Q6, Q9:** Open a terminal in the question folder and run `node solution.js`.
- **Q2, Q4, Q5, Q7, Q8:** Open the question's `index.html` file in a browser. The JavaScript is in a separate `script.js` file.
- No frameworks or external libraries are used.

Each question is kept separate. The browser-based questions include simple HTML pages so you can test the JavaScript form and DOM behavior.
