LECTURE 1–3 JAVASCRIPT ASSIGNMENT — SOLUTIONS

This folder contains 10 separate JavaScript files, one for each assignment question.
The code uses core JavaScript only and includes beginner-friendly comments.

How to run:
1. Install Node.js, or open a browser's Developer Tools and choose Console.
2. Run one .js file at a time.
3. With Node.js, open a terminal in this folder and run:
   node Q1_Personalized_Login_Greeting.js
   Replace the filename with the question you want to test.

Before testing:
- Change example values such as names, marks, expenses, salary, guesses, age, and citizenship.
- Q7 generates a new random secret number each time.
- Q9 generates a random arithmetic question each time.

Note:
- Q3 calculates the average across the five expense categories.
- Q10 follows the exact outcome labels in the assignment, including “Eligible to vote only” for citizens aged 18–20.
